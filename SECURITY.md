# Security Policy

## Поддерживаемые версии

Поскольку проект находится в активной разработке, поддерживается только **последняя версия** на ветке `main`.

| Версия     | Поддержка          |
| ---------- | ------------------ |
| Latest     | ✅ Активно          |
| Older      | ❌ Не поддерживается |

## Сообщение об уязвимости

Если ты нашёл уязвимость безопасности (даже если игра пока небольшая), пожалуйста, **не создавай публичный issue**.

Напиши мне напрямую через GitHub (открой Issue с меткой `security` или свяжись через другие каналы, если они указаны).

Я постараюсь ответить как можно быстрее.

Спасибо за помощь в поддержании проекта в безопасности!
