# Хаос & Прибыль (Chaos & Profit)

> Фановая некоммерческая игра про молодого предпринимателя в странном мире, где нужно крутить слот-машину, строить бизнесы и удерживать непредсказуемых клиентов, пока растущий Рейтисурд не разрушил всё.

**Жанр**: Idle + слот-машина + management с элементами риска, коррупции и хаоса.

**Текущий статус:** Активная разработка Pygame-версии. Консольная версия в основном завершена.

## Особенности

- Слот-машина как центральный геймплей
- Система бизнеса и сделок с моральным выбором
- Механика Рейтисурда — чем выше хаос, тем выше риск и награда
- Проклятия, перманентные последствия и искажённая экономика
- Оффлайн-прогресс и сбросы с механикой «цена успеха»

## Как запустить

### Основная версия — Pygame (рекомендуется)

```bash
python -m src.chaos_profit.ui_pygame
```

### Консольная версия (для быстрого тестирования и баланса)

```bash
python -m src.chaos_profit.ui_console.console_app
```

> **Примечание:** Консольная версия — это временный инструмент для тестирования механик. Полноценный игровой опыт доступен в Pygame-версии.

## Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Wichrisen/chaos-profit.git
cd chaos-profit

# Рекомендуется создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows

pip install -r requirements.txt
```

> **Примечание:** Полноценная playable-версия находится в активной разработке.

## Структура проекта

- `src/chaos_profit/core/` — игровая механика и логика
- `src/chaos_profit/ui_pygame/` — основная версия игры (Pygame)
- `src/chaos_profit/ui_console/` — консольная версия для тестирования
- `assets/` — изображения и звуки
- `packaging/` — конфигурация сборки (PyInstaller)
