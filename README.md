# Хаос & Прибыль (Chaos & Profit)

> Фановая некоммерческая игра про молодого предпринимателя в странном мире, где нужно крутить слот-машину, строить бизнесы и удерживать непредсказуемых клиентов, пока растущий Рейтисурд не разрушил всё.

**Жанр**: Idle + слот-машина + management с элементами риска, коррупции и хаоса.

**Текущий статус:** Активная разработка Pygame-версии. Консольная версия в основном завершена.

## Как запустить

### Pygame-версия (рекомендуется)

```bash
python -m src.chaos_profit.ui_pygame
```

### Консольная версия (для быстрого тестирования)

```bash
python -m src.chaos_profit.ui_console.console_app
```

**Доступные команды:**
- `status` / `s` — текущее состояние
- `advance <минуты>` / `a <минуты>` — продвинуть время (например `a 60`)
- Быстрые команды: `1m`, `5m`, `10m`, `30m`, `1h`, `2h`
- `deals` / `d` — показать текущую сделку
- `accept` / `refuse` — принять или отказаться от сделки
- `potions` / `p` — инвентарь зелий
- `use <тип>` — использовать зелье (например: use 10min, use permanent, use suppression)
- `shop` / `buy` — открыть магазин и купить новый бизнес
- `spin` / `slot` / 🎰 — крутить слот-машину (1 Клонета)
- `upgrades` / `up` + `upgrade <n> <growth|efficiency|resilience>` — улучшения бизнесов
- `reset` — полный сброс прогресса (с подтверждением)
- `upgrades` / `up` — посмотреть улучшения бизнесов
- `upgrade <номер> <тип>` — улучшить бизнес (growth / efficiency / resilience)
- `spin` / `slot` / 🎰 — крутить слот-машину (стоит 1 Клонету)
- `save`, `reset`, `help`, `quit`

Это временный инструмент для ручного тестирования механик.

В статусе теперь подробно показываются активные эффекты на каждом бизнесе + индикатор давления Рейтисурда (Calm → Extreme).

## Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Wichrisen/chaos-profit.git
cd chaos-profit

# Рекомендуется создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows

pip install -r requirements.txt
```

> **Примечание:** Полноценная playable-версия находится в активной разработке.

## Структура проекта

Ключевые папки:

- `src/chaos_profit/core/` — игровая логика (экономика, слот, хаос, эффекты)
- `src/chaos_profit/ui_pygame/` — основная графическая версия (Pygame)
- `src/chaos_profit/ui_console/` — консольная версия (для быстрого тестирования)
- `assets/` — изображения и звуки
- `docs/` — документы по дизайну и балансу
- `packaging/` — файлы для сборки (PyInstaller)

## Цели первой версии (MVP)

- Полноценный core loop: Клонеты → слот → Бизнета → бизнесы → пассивный доход + хаос
- Несколько бизнесов с разными механиками
- Система Рейтисурда, влияющая на риск и награды
- Сохранения + оффлайн-прогресс
- Работающая Pygame-версия
