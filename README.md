# Хаос & Прибыль (Chaos & Profit)

Фановая некоммерческая игра про молодого предпринимателя в странном мире, где нужно крутить слот-машину, строить бизнесы и удерживать непредсказуемых клиентов, пока растущий Рейтисурд не разрушил всё.

**Жанр**: idle + слот-машина + management с элементами риска и хаоса.

## Структура проекта

См. план разработки в `.grok/sessions/.../plan.md` (или в чате с Grok).

Ключевые папки:
- `docs/GDD.md` — главный документ с механиками и балансом (будет создан следующим)
- `src/chaos_profit/core/` — чистая логика (экономика, слот, хаос)
- `src/chaos_profit/ui_console/` — временный консольный интерфейс
- `src/chaos_profit/ui_pygame/` — основной 2D-интерфейс
- `tools/balance_sim.py` — симуляции для балансировки

## Цели первой версии (MVP)

- Полноценный core loop: Клонеты → слот → Бизнета → бизнесы → пассивный доход + хаос
- 5–8 бизнесов
- Рейтисурд 1–15 с реальным влиянием на риск/награду
- Сохранения + оффлайн-прогресс
- Играбельно 15–30 минут без багов
